## How to run
1. Install Python 3.
2. Open the project folder in a terminal.
3. Run the command:

python3 bugboard.py

## Features that work
1. Log a bug with title, module, severity and steps.
2. Assign a bug to a developer.
3. Update bug status using valid lifecycle transitions.
4. Count how many times a bug is reopened.
5. Report open bugs by age and find the module with the most bugs.

Additional feature:
- View all reported bugs.
